# Chattery

Chattery is a World of Warcraft addon that removes the size limit on chat messages, similar to addons like [Emote Splitter](https://www.curseforge.com/wow/addons/emote-splitter) or [Unlimited Chat Message](https://www.curseforge.com/wow/addons/unlimitedchatmessage).

# Features

*   Automatically splits long chat messages into chunks the game can support
*   Preserves TRP chat highlighting across messages
*   A character counter on the chat editbox
*   Optional auto capitalization and punctuation
*   Undo (ctrl-z) support if you accidentally delete your message
*   100% human-written code

# Compatibility

## Friends

*   Works great alongside [Eavesdropper](https://www.curseforge.com/wow/addons/eavesdropper), [Languages](https://www.curseforge.com/wow/addons/languages), and [Yapper EditBox](https://www.curseforge.com/wow/addons/yapper-editbox).

## Conflicts

*   Incompatible with other chat message splitters like [Emote Splitter](https://www.curseforge.com/wow/addons/emote-splitter) or [Unlimited Chat Message](https://www.curseforge.com/wow/addons/unlimitedchatmessage).
*   Outdated RP addons often cause issues when sending chat messages while in instances, or in combat. Ensure your addons are up-to-date, and uninstall any that haven't been updated for Midnight.
    *   The most common suspects are Listener and CrossRP. If you have those enabled, you will encounter issues sending messages until they're updated for Midnight.
